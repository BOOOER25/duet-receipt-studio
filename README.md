# 双人消费小票视频工作室

参考视频： https://www.douyin.com/video/7708060427779378533

以中央日期轴展示双方的消费或热量记录，打印机快速吐出一截、停顿，再打印下一截。同一天的双方记录归到同一段，各侧内部按消费时间排序，没有记录的一侧留空。每段出纸不超过 0.36 秒，汇总出纸不超过 0.48 秒，其余时间纸张完全静止，供观看和阅读。金额随已经完整打印的日期一起累计。预览、视频和完整长小票 PNG 使用同一套日期轴布局。视频中的结构为参考，背景、排版和绘制代码为本项目实现。

## 使用

1. 在「画面设置」配置单位、时长、背景、双方名称和头像。可添加自己的背景音乐。
2. 在「双方明细」配置每笔名称、金额、消费日期、时间和图片。每方最多 18 笔。日期决定中央时间轴，双方同步按日期打印；消费时间决定当天内部的排列顺序。
3. 在「素材库」上传多张图片，选择「抠图」生成透明 PNG。原图保留，抠图结果可以复用及下载。商品大小可独立调整。
4. 拖动预览进度检查任意画面；保存 1080×1920 PNG，或选择 720p / 1080p 录制 30fps 视频。
5. 浏览器支持 MP4 时导出 MP4，否则导出 WebM；页面会显示实际格式和视频预览。录制按实际时长进行，切换后台自动取消，防止导出缺帧视频。不需要屏幕、麦克风或摄像头权限。

## 数据

素材上传指从设备选择图片进入本机素材库，不会将用户图片上传到 GitHub。配置、图片和音乐自动存入当前浏览器的 IndexedDB；空间不足时会提示先保存当前图片或视频。每个项目独立保存草稿，清除浏览器数据会清除草稿。

2026-11-24：每笔素材明细支持完整日期选择。按双方全部明细中最早至最晚日期的跨度（首尾日期均计入）自动切换中央标签：不超过 7 天显示「周一…周日」；超过 7 天，无论同月、跨月或超过 31 天，均显示「1号…31号」。按完整年月日排序、归组，跨月同号不会合并。无记录的日期不额外插入空白段。旧草稿没有日期时，统一补为升级当天的本机日期，保留原有素材、消费时间、金额和背景；之后自动保存日期，刷新不会再次变化。

2026-11-23：已移除页面顶部品牌栏和导入／导出入口，以及小票的顶部 slogan、英文标语和底部宣传文案。旧草稿中的标题、底部文案和独立出现时间仍可读取，但不再参与小票排版及动画。

纸张两侧使用淡色细边，刚开始吐纸时上沿保持不透明；纸张填满可见区域并开始向上滚出后，上沿再逐渐启用透明渐变。透明遮罩适配自定义背景，完整小票 PNG 保留完整的不透明纸张。

预设新增「小鱼爪印」（默认，使用提供的透明图配奶油色底）和「暖黄爪印」（参照示意图用 Canvas 绘制）。打印机中央装饰替换为提供的猫咪贴图，两侧金额屏保留。原有三种配色仍可选择。新草稿以及尚未使用新预设的旧配色草稿采用小鱼默认背景；旧草稿若有自定义背景，则保留自定义素材和配色。用户选定预设后刷新会保留选择。内置贴图与用户上传的素材库分开加载，不占用素材库容量。

支持 JPG / PNG / WebP，单图 20 MB，解码后最长边限制为 1400；音乐 20 MB；最多 100 项素材；项目文件上限 80 MB。所有上传的文字均通过 textContent 或 Canvas 绘制。导入仅接受白名单数据字段与嵌入的图片/音频，不加载项目文件里的外部链接。默认示例使用已有公开演示商品图片，只用于演示，可替换为自己的素材。

免费抠图采用 `@imgly/background-removal` 1.7.0，Worker 中运行 CPU `isnet_quint8`。首次从 IMG.LY 官方 CDN 下载约 40 MB 运行资源，之后受浏览器缓存影响。处理可取消、失败可重试，也可直接上传已有透明 PNG。CPU 性能和 CDN 可访问性影响处理速度。

## 开发

需要 Node.js 20+。

```sh
npm ci
npm test
npm run build
npm start
```

默认 http://127.0.0.1:4182 ，可用 PORT 环境变量修改端口。

`receipt-timeline.js` 负责日期标签、日期归组、分段吐纸节奏和合计；`main.js` 是编辑器源码；`draw.js` 是 Canvas 渲染；`core.js` 是日期、数据和金额规则；`media.js` 负责上传及抠图；`storage.js` 负责 IndexedDB；`recorder.js` 负责浏览器录制；`project.js` 选择项目类型。

`npm run build` 在根目录生成 `app.js`、`cutout-worker.js` 及依赖许可说明，`index.html` 直接加载构建结果。仓库同时提供源码和静态产物，可直接部署 GitHub Pages（main 分支 / root）。源码下载为 `source.zip`。构建后通过浏览器访问 HTTP 地址，不要直接双击 file://。
